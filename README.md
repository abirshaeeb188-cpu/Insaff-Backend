# Sand & Concrete Delivery

A modern web application for a Sand & Concrete Delivery business. The platform provides customers with information about available construction materials, delivery services, pricing, and contact options.

## 🚀 Features

- Sand and concrete delivery services
- Construction material information
- Service and pricing sections
- Contact / inquiry functionality
- Responsive design for desktop, tablet, and mobile
- Fast and modern user interface
- SEO-friendly pages
- Easy-to-maintain project structure

## 🛠️ Technologies

- Next.js
- React
- TypeScript
- Tailwind CSS
- Node.js
- JavaScript/TypeScript
- Vercel

## 📦 Materials & Services

The platform can be used to showcase and manage:

- Construction Sand
- Concrete
- Gravel
- Aggregates
- Road Base
- Other construction materials
- Delivery services

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git
```

### 2. Navigate to the project

```bash
cd YOUR_REPOSITORY
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open your browser and visit:

```text
http://localhost:3000
```

## 🔐 Environment Variables

Create a `.env.local` file in the root directory and add the required environment variables.

Example:

```env
NEXT_PUBLIC_SITE_URL=
NEXT_PUBLIC_API_URL=
```

Do not commit `.env`, `.env.local`, API keys, passwords, or other sensitive credentials to GitHub.

## 🏗️ Build for Production

```bash
npm run build
```

Start the production server:

```bash
npm start
```
